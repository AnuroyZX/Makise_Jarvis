# Procedimiento: Diagnóstico y Optimización de Recursos

Cuando el usuario pregunte por el rendimiento del PC o pida optimizar/liberar memoria:
1. Ejecuta la herramienta de diagnóstico y recorte (`system_optimize_ram`) del `ResourceGovernor`.
2. Informa cuánta RAM física ocupa Amadeus Kurisu, el porcentaje global de RAM del sistema y confirma si se cerraron navegadores efímeros inactivos.
