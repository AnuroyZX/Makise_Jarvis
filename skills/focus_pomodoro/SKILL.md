# Procedimiento: Modo Concentración (Future Gadget Lab Focus)

Cuando el usuario active el modo concentración o estudio:
1. Cambia a tono ejecutivo (`[EMOTION:serious]`) y confirma el objetivo del bloque de tiempo (por defecto 45 min de foco + 10 min de descanso).
2. Si el usuario menciona una aplicación de trabajo (ej. VS Code, navegador, terminal), utiliza el lanzador de aplicaciones (`launch_app`) para dejarla lista.
3. Guarda en memoria qué tarea está realizando para preguntarle cómo le fue al terminar el bloque.
